## Images
Figma export is disabled. Assets have been requested from the design owner; until they arrive, every image path points to a **neutral WebP placeholder**. The placeholders are generated by `scripts/generate-placeholders.mjs` into `public/images/placeholders/`.

| File | Ratio | Used for |
|---|---|---|
| `square.webp` | 1:1 | product shots, category tiles, medium and small card images |
| `portrait.webp` | 3:4 | PDP product image, lifestyle images, large vertical card, hero below `lg` |
| `landscape.webp` | 16:9 | hero from `lg`, large horizontal card |
| `banner.webp` | 12:5 (2.4:1) | product and store banners on `md`/`lg`; wide bento cards |
| `banner-portrait.webp` | 4:5 | banners on mobile |

Each image is shown with `fill` + `object-cover` inside an aspect box, so a placeholder only needs to be close in ratio. When real assets arrive, put them in `public/images/products/` and change only the JSON paths.
